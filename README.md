
# 🔐 Password Generator

A simple and secure password generator built using HTML, CSS, and JavaScript.

## 🚀 Features

- Generate random passwords
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Password strength checker
- Copy password
- Show / Hide password
- Dark mode
- Password history
- Clear history
- Save history using localStorage
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## 📌 How to Use

1. Select the password length.
2. Choose the character types.
3. Click Generate Password.
4. Copy the generated password.
5. Use Show / Hide Password to view the password.
6. Check the password strength.
